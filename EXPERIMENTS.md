## Выполненные серии

Обе модели проверены в каждой серии. Устройство: CPU,
число потоков PyTorch: 4.

| Серия | Сценарии | Агенты | Лимит шагов | Эпизоды |
|---|---|---|---|---|
| Random | Пять карт 000–004, seed среды 0 | 8, 16, 32, 64 | 128 | 40 |
| Mazes | Пять карт 000–004, seed среды 0 | 8, 16, 32, 64 | 128 | 40 |
| Warehouse | wfi_warehouse, seed среды 0–4 | 32, 64, 96, 128 | 128 | 40 |
| Cities-tiles | Восемь городских фрагментов, seed среды 0 | 64, 128 | 256 | 32 |

Всего: 152 эпизода в сериях и два проверочных запуска.
В Random и Mazes номера 000–004 обозначают карты, а не seed среды.

В каждой папке:
- episodes.csv: показатели каждого эпизода;
- summary.csv: сводка по модели и числу агентов;
- settings.json: параметры запуска.

## Основные показатели

- ISR: доля агентов, достигших целей.
- CSR: успех всей группы, 1 — успех, 0 — неуспех.
- success_rate: доля успешных эпизодов.
- SoC: суммарная стоимость путей.
- makespan: время завершения последнего агента.
- ep_length: длина эпизода в шагах.
- runtime: метрика времени, возвращённая программой.
- wall_seconds: измеренное скриптом время выполнения run_episode.

Средние SoC и makespan в summary.csv рассчитаны только
по успешным эпизодам. При разных наборах успешных задач
они не дают прямого сравнения качества путей моделей.

## Повторный запуск

Запускать из корня репозитория после установки зависимостей
по исходному README.md авторов:

    conda activate mapf-gpt
    export OMP_NUM_THREADS=4
    export MKL_NUM_THREADS=4
    python run_random_small.py
    python run_mazes_small.py
    python run_warehouse_small.py
    python run_cities_small.py

Необходимые веса:
- weights/MAPF-GPT-2M.pt
- weights/MAPF-GPT-6M.pt

Инструкция получения весов находится в README.md.
Каждый запуск создаёт новую папку результатов с датой и временем.
